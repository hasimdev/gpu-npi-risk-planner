# RACI

R = Responsible, A = Accountable, C = Consulted, I = Informed

| Activity | TPM | Launch lead | Silicon ops | Memory & packaging sourcing | Board eng | Manufacturing | Finance |
|---|---|---|---|---|---|---|---|
| Maintain BOM model and assumptions | A/R | I | C | C | C | C | I |
| Run simulation before each gate | A/R | I | I | I | I | I | I |
| Phase-gate reviews (EVT/DVT/PVT/MP) | R | A | C | C | R | R | I |
| Supplier risk register | A/R | I | R (die) | R (HBM, packaging, substrate) | R (PCB, power, thermal) | R (test) | I |
| Packaging and HBM allocation | C | I | C | A/R | I | I | C |
| Second-source qualification | R | A | C | R | R | C | C |
| Expedite and premium spend approval | R | C | I | C | I | I | A |
| Launch date commitment | R | A | C | C | C | C | I |

One person fills every role in this portfolio version. The table shows how the work would be split on a real program, and who has to agree before a date moves.
